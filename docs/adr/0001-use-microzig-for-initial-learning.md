# ADR 0001: 初期学習では MicroZig を採用する

## Status

Accepted

## Context

このリポジトリは、RP2040 ベースの 3 キーキーボードを題材に、Zig で組み込みキーボードファームウェアを段階的に学ぶためのプロジェクトです。

直近の学習対象は、GPIO 入出力、キースキャン、チャタリング対策、USB HID です。MicroZig を使わずに進める場合、startup、linker script、boot、UF2 生成、HAL などの足回りを早い段階で自分で扱う必要があり、現在の学習目的から外れる作業が大きくなります。

一方で、現行の MicroZig 安定版は Zig `0.15.1` を前提としており、将来的には Zig `0.16.0` 以降への追従が必要になる見込みです。

## Decision

初期 bring-up では MicroZig を採用します。

まずは MicroZig の上で、ビルド、LED 点滅、キー入力、debounce、USB HID までを段階的に学びます。Zig `0.16.0` 対応版の MicroZig が利用できるようになった時点で、依存関係更新と API 移行を独立した学習テーマとして扱います。

## Consequences

- 初期段階では、キーボードファームウェアの本筋に集中しやすくなります。
- startup や linker などの低レイヤー学習は後回しになります。
- MicroZig のバージョン追従に合わせて、将来的に移行作業が発生します。
- 将来、RP2040 の足回りをより深く理解したくなった場合は、MicroZig なしの別ルートを追加で検討できます。
